Communication Paths
===============================================================================

Kali  ---------------- ICMP ------------------> Windows
Kali  ---------------- SMB -------------------> Windows
Kali  ---------------- RDP -------------------> Windows
Kali  ---------------- HTTP ------------------> IIS Server
Kali  ---------------- DNS -------------------> DNS Queries
Kali  ---------------- SSH -------------------> Linux Targets
Windows ------------ Syslog (UDP 514) -------> Kali Rsyslog
Windows ------------ Event Logs -------------> NXLog
NXLog -------------- Forward Logs -----------> Kali
Suricata ----------- Monitor Traffic --------> Host-Only Interface
Tcpdump ------------ Capture Packets --------> PCAP Files
