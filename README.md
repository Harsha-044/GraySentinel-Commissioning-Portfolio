# GraySentinel Commissioning Portfolio

## Overview

Welcome to my **GraySentinel Commissioning Portfolio**.

This repository documents my hands-on **45-day cybersecurity training journey**, covering offensive security, defensive security, threat hunting, incident response, detection engineering, Windows and Linux security, and scripting. Throughout this program, I completed practical labs, created detection rules, analyzed logs, investigated attacks, and documented findings in a structured portfolio.

The goal of this portfolio is to demonstrate practical cybersecurity skills that align with Security Operations Center (SOC), Blue Team, Detection Engineering, and Cybersecurity Analyst roles.
